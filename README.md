# Earth Trend Detective

What has really changed where you live? Pick any place on Earth and Earth Trend Detective pulls 45 years of NASA climate data, compares the last decade with the 1981–2010 average, tests which changes are statistically significant, finds variables that changed together as possible drivers, and explains the results in plain English.

Built for the 2026 NASA Space Apps Challenge: **Be an Earth System Trend Detective!**

## What it does

1. **Gather:** fetches monthly data for the chosen point from the NASA POWER API (1981 to the latest full year): average, daytime high and nighttime low temperature, rainfall, humidity, root-zone soil wetness, sunlight at the ground, and wind speed.
2. **Compare:** averages the last 10 years and compares them with the 1981–2010 baseline.
3. **Test:** turns monthly values into yearly values (removing the seasonal cycle), then runs a Mann-Kendall trend test with Sen's slope. p < 0.05 is reported as significant, p < 0.10 as a possible trend.
4. **Connect:** matches variables that changed together to known physical links (for example, drier soil and hotter days), and reports the detrended year-to-year correlation as supporting evidence. These are hypotheses, not proof of cause.
5. **Explain:** Google Gemini writes a short plain-English summary from the computed numbers only.

## NASA data

- **NASA POWER** (Prediction Of Worldwide Energy Resources), NASA Langley Research Center, Monthly API. Meteorological values are derived from NASA GMAO's MERRA-2 reanalysis. Parameters: `T2M`, `T2M_MAX`, `T2M_MIN`, `PRECTOTCORR`, `RH2M`, `GWETROOT`, `ALLSKY_SFC_SW_DWN`, `WS2M`.

## Run it locally

Requires Node.js 18.18 or newer.

```bash
npm install
cp .env.example .env.local   # then paste your Gemini API key into .env.local
npm run dev                  # open http://localhost:3000
```

Optional, recommended before a demo: save backup copies of NASA data for the demo places, so the app still works if NASA's service is slow.

```bash
npm run save-demo
```

## Deploy

Import the repository in Vercel, add `GEMINI_API_KEY` under Settings → Environment Variables, and deploy.

## Limitations

- NASA POWER values represent a grid cell of roughly 50 km, not a single street.
- The Mann-Kendall test assumes years are independent; strong year-to-year persistence can make trends look more significant than they are.
- Possible drivers are physical hypotheses based on co-occurring changes, not attribution.
